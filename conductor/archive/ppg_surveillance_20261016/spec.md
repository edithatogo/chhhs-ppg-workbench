# Broader source surveillance

Implement one selected, accessible authoritative source-family pilot for a named
PPG task. Source-family choice is required before live acquisition. Reuse qualified
browser/Microsoft routes; preserve raw snapshots and exact provenance. Do not crawl,
index the archive, introduce AI processing/providers or change permissions.

A bounded local component may preserve explicitly acquired bytes, validate their
hashes and compare the same source identities/URL scope. Keep printed/native edition,
policy authority, URL/file identity and local case decisions distinct. HTML byte
changes are review signals, not semantic changes. Failed or missing acquisition is
an exception, never retirement; never reuse denied/stale bodies as fresh content.

Link affected candidates only through explicit existing CaseUID/sourceKey mappings.
No source/case/checkpoint writes, inferred current authority, notifications or
background schedule. Live authenticated capture/retrieval and report destination
readback are necessary for native pilot delivery; local tests alone cannot close it.
