# Content-rule diagnostic review

The existing module validator checked declarations but did not evaluate presence.
The new evaluator is read-only, edition-bound and exclusive-output. It distinguishes
unknown applicability from a verified exclusion, refuses malformed/mixed/duplicate
inputs, requires reviewed text and respects block-level variant scope. Proposed
or empty/unverified rule sets cannot clear readiness. No clinical completeness,
permission or automatic progression is inferred from presence. Native before/after
source/reviewer exports match171 rows. Seven evaluator/four existing capture tests
cover meaningful refusal/unknown/preservation cases, with actual CLI file refusal.
The fifteen-member downloaded v2 archive reproduces report and tests in isolation;
four native evidence files have exact readback/inherited access/zero-create replay.
Version1 is retained as narrower historical evidence. No production operator CLI
step, native state writer, new rule authority or frozen workflow change is introduced.
