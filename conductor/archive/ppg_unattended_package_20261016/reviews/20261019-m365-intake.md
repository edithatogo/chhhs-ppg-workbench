request. Its Office Script generates the fixed seven-field cover and existing
frozen-pack ZIP in M365. The maintained template is compiled once per template
revision; no local per-run manifest or document generation is needed.

Two implementation findings were corrected during native qualification: request
property rechecks must compare authoritative values/version fields rather than
SharePoint's per-response `odata.id`; connection display metadata can be
normalised by the service, while connector identity, connection name, source and
tier must match. The manual launch UI also rejects a blank optional integer;
the field now accepts optional text, and the flow explicitly handles blank/default
input before converting the request ID. No authentication, consent, licence or permissions were changed.

The actual Power Automate Run dialog was exercised with the optional request ID
left blank; the portal confirmed the run started. No CLI is needed to launch an
ordinary job.

The source builder is pure and keeps actual bindings private. Focused tests cover

separate revisions, non-overwrite writers and optional PDF failure boundaries.
Legacy cloud-kernel and fixed-cover regression checks also pass.

The selected shape retains conservative 2 MB complete raw / 4 MB wire limits. The
flow is manual-start and unattended thereafter, with concurrency one and no
schedule. The final qualified graph is retained On, with its exact previous
