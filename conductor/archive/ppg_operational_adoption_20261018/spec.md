# Ordinary-user adoption and benefit measurement

Establish that the existing workbench can be operated by its intended users and distinguish technical availability from observed benefit. Extend existing process measures and observation format, not a second analytics engine.

## Requirements and acceptance

Define matched old/new preparation tasks, hands-on time, elapsed stage waits, corrections, assistance and outcomes. Record observation date, sample size, exclusions and missing data. Preserve source/period identity and denominator definitions; age since creation is not review turnaround.

Use the actual intended principal for ordinary-user evidence; never impersonate or infer access from the current admin principal. If an available authorised participant is absent, record that precise gap while completing the observation kit. No invitations are sent. Full-cycle acceptance consumes the existing lifecycle proof. Real use requires subsequent human participation; no clinical work is required to close the technical instrumentation slice. Benefit conclusions require actual observations.

Power BI is optional: prove a permitted existing workspace/refresh route and audience access before using it; a PPU author's licence does not licence all readers. Reconcile every measure to existing definitions. Retain Lists and CSV fallback.

## Boundaries and eligibility

Follow [the capability assessment](../../../docs/maturity-capability-plan-20261018.md).
The upstream register is externally owned and read-only. Use existing Lists,
library, identities and writers; preserve source fields, human edits and history.
Before native changes recheck account, exact target, licence/action/connection,
environment/DLP, role access and existing notification effects. No purchase,
trial, new consent, permissions, source changes, messaging, assignment, clinical
approval or publication is authorised by this plan. Use a documented native/manual
fallback if a candidate fails eligibility; mark that feature deferred, not delivered.
Keep real records and receipts in approved storage/ignored .local/, not Git.
