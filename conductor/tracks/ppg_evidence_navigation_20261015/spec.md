# Evidence finder and archive navigation

Make existing canonical evidence easier to find for a coordinator/CMO without adding an AI dependency. Improve task-oriented metadata, links, library views and ordinary supported search across the preserved archive, templates and working evidence.

## Deliverables and acceptance

Inspect existing all-files/CMO views and archive indices before adding anything. Use a small fictional or pre-agreed task set: locate a captured policy, the current example pack, a reusable template and source-sync evidence. Distinguish captured sources, working drafts, technical evidence and any separately evidenced current authority. Preserve source URLs, capture dates, hashes and the meaning of the CMO relevance subset.

Reuse canonical resources; only additive navigation/derived metadata changes are in scope. Downloaded .captured Office originals may not be searchable: measure supported search coverage and expose a clear index/download route, never rename or rewrite originals to make search work. Derived searchable copies are a separate explicit implementation choice with provenance, not replacements.

A user can reach each selected task from Start Here, reapplication produces no duplicate views/links, all-files and subset navigation remain correct, no permissions change, and original archive bytes/hashes remain preserved. Report observed task success and search gaps, not invented time savings.

## Exclusions

No AI agent, bulk recapture, document assessment, archive authority judgement, ownership inference, new tabs or unattended content changes.
