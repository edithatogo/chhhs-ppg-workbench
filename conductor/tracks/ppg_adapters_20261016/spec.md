# CareOps / Atlas adapters

Implement one concrete adapter only after its consumer/workflow and exchange
contract are defined. Inspect existing repositories read-only; preserve their
owners, source namespaces, rights and private data boundaries. No speculative
common framework, receiving endpoint, identity crosswalk or data transfer.

Common provenance concepts may be reused, but local policy status cannot become
simulation validation, medicine equivalence, regulatory/funding/formulary evidence
or publication rights. Private policy data cannot use a public-only dataset
federation contract. Portable tool code is not a deployed receiving service.

Qualify exact current consumer commit, interface/access, desired direction and
fictional fixture. Verify actual accepted output/lookup, integrity, missing/denied
and schema drift behavior before claiming delivery. Native consumer writes,
real-data transfer, publication and clinical decisions are not inferred.
