# Native form-to-Word generation — conditional pilot

Determine whether SharePoint structured document generation can reduce manual DRAFT preparation, then demonstrate one bounded form-to-Word path if existing tenant entitlement and configuration permit it. This track commissions eligibility investigation and a plan; deployment remains conditional on verified existing access, licence/feature availability and permitted data scope.

## Eligibility and deliverables

Recheck feature-specific official Microsoft documentation at execution time. Inspect the exact existing library/user entitlement using already authorised tools. Record availability, maker/runtime licensing, preview conditions, charging implications, supported DOCX controls and safe output location. Do not activate billing, allocate licences, enable a tenant preview or broaden access to make the pilot pass. If a material requirement is unavailable, retain the report and fallback recommendation; mark the pilot deferred/new, not completed deployment.

If eligible, reuse a maintained DRAFT template and fictional inputs to generate one editable DOCX in a distinct test area. Preserve template/original/archive bytes. Record template version, input manifest, generated-file identity and provenance; label generated output DRAFT / HUMAN CHECK REQUIRED. Qualify repeated generation and failure behavior without overwriting human edits. Prefer a native form, adding preview flow actions only if required and proven available.

## Acceptance

Eligibility evidence precedes build. Generated fictional fields match inputs, output opens/editably saves, and repeat generation preserves earlier output and manual edits. Missing/invalid data and failure remain visible. Native save/run/readback and downloaded bytes are recorded separately from local preparation. Compare usability with the working manual generator/assembler and recommend keep/drop; no production cutover is implied.

## Exclusions

No AI content judgement, actual policy review, billing/preview enablement, licence purchases, production flow conversion, source/case updates, new recipients, clinical publication or replacement of existing working tools without evidence.
