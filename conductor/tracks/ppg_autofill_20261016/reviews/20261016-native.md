## Findings and resolution

### High — Settled reprocessing overwrites a corrected suggestion
Initial reads after retry still showed the corrected value, but the later Finished
result overwrote it. The earlier v0.2 preservation claim was withdrawn. All three
native prompts were disabled and read back Off, the exact correction was restored
in version5.0, and source bytes/history were retained. The corrected value remains
visible in the native view. Superseded v0.2 technical assets were recycled; v0.3
links explicitly state Off/unsafe reprocessing. No automatic correction-preserving
reprocessing or production promotion is claimed. This is a documented native
limitation with a tested stop/export/history/restore path, not a hidden passing case.

### Medium — CLI exit0 did not establish first-time saved configuration
The first convenience command returned success while AutofillInfo remained null.
Readback caught it. The CLI's update endpoint saved the prompt; subsequent standard
set commands and exact field/prompt/enabled-state readback succeeded. The guide
requires readback and reports the creation-path limitation rather than treating
exit0 as proof.

### Authentication blocker resolved
Toolkit-style MSAL interactive authentication with PKCE and form_post succeeded
inside the CLI process/cache. Empty/query modes failed. The maintained adapter
uses the same public MSAL API, explicit app/tenant/connection arguments and the
resource's existing .default scope; it neither transfers tokens nor edits the
installed package. No new application, consent or permission grant was introduced.

unreadable PDF Failed with empty metadata; initial/revised outputs; late overwrite;

repeat adoption without another page/manifest version. Detailed receipts remain

## Decision
Accept the technical fictional pilot **Off**, with native overwrite risk explicit
and recovery demonstrated. No further source-code defects identified in this
bounded review. Human semantic evaluation, production material processing, licence/
billing audit and any wider rollout remain separate activities. Keep the archive,
source catalogue, cases and business decisions outside Autofill. Do not re-enable
over corrected values without a newly qualified preservation strategy.
