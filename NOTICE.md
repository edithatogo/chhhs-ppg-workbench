# Third-party tooling and publication boundary

Conductor is an independently maintained Apache-2.0 project, referenced by an
immutable Git submodule pin. Its licence and notices remain with that upstream
checkout; no upstream files have been modified or copied into the project context.

No public licence is selected here for the original CHHHS project material.
The publishing helper defaults to a private repository. Private visibility does
not permit storing operational source data or credentials contrary to the
project's data-handling rules.
