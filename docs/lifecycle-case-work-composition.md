same-site evidence folder. It is a selection, not an assertion of its hash or
readiness. The GET-only [prepared reader](../tools/lifecycle/build_prepared_revision_check.py)

output revision, final edited file identity, opaque ETag, native version and hash.

native edit/readback, retry preservation and original preservation. Case-generation
inputs must still match; only the later evidence-link selection is exempted from
that snapshot comparison. File, receipt, template, source, baseline and current
case are checked again before returning eligibility.
