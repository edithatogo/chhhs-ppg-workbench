# Reviewing retained sources without catalogue identity

Use `scripts/ppg_unassociated_review.assess` for a retained corpus source with no
catalogue retrieval association. Existing associated sources continue through the
pair-review route. Do not invent a catalogue identity to appraise useful guidance.
This is a local manual-review validator, not native AI or a scheduled service.

Supply the frozen screen/index, actual source PDF/text bytes, historical subject
inspection/inventory, versioned criteria, findings and source observations. The
validator checks original/extraction/subject hashes, passage locations, criteria,
actions, revision uncertainty and absence of human decisions. Empty reviews,
changed bytes, fabricated passages, duplicate findings and already-associated
sources are refused. It records criteria and content provenance while keeping
catalogue identity and current authority unverified. It does not establish that a
reviewer read every page; retain actual read scope/visual gaps in the evidence receipt.

`ppg_corpus_reconciliation.reconcile(..., unassociated_reviews=[report])` accepts
these frozen source-review envelopes as separate corpus evidence. It checks envelope
hash, source representation, no catalogue association/identity/authority/decision and
unique source index. It does not replace passage validation: prepare the report
through `assess` first. The default invocation still reproduces the prior frozen
corpus report exactly. Source-only reviews never increment catalogue pair coverage.
