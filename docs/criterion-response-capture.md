# Complete criterion responses without invented findings

The source-only review validator accepts optional `criterion_responses` using the
existing criteria register's choices: `supported_finding`, `no_issue_in_checked_scope`,
`not_applicable_with_rationale` and `unknown_missing_evidence`. The register/criteria
version remains unchanged. Optional response capture is version1.0.0.

When supplied, every declared criterion needs one unique response, rationale,
statement, source/subject citations, exact finding links and explicit
`historical_retained_text_only` scope. Supported responses require supported findings;
unknown findings remain unknown. No-issue/not-applicable cannot conceal a finding.
Missing/one-sided/fabricated evidence, contradictory responses, current-compliance
scope and supplied human decisions are refused. Empty findings without a complete
response set still fail. Legacy findings-only output shape/hash is preserved.

A no-issue response means only that no issue was identified in the stated retained
comparison. It does not assert current policy sufficiency, accreditation compliance,
clinical safety, legal authority, actual implementation or human approval. Unknown
and not-applicable are separate responses with evidence/rationale, not silent passes.

ambiguous wording remain visible. No person identity is inferred from source photographs.

Other272 source pairs and full legacy raw-source reexecution remain external checks.
Detailed records/bindings remain private. Nine fictional regressions/57 focused tests pass.

This implements existing choices within the published manual eight-criteria review
step; no new lifecycle state, business transition, flow, schedule or notification.
Published workflow1.4 and earlier reports remain preserved. Current V7/template,

## Use responses within the commissioned scope

Do not manufacture findings, but also do not use the unassociated-source count to
create unnecessary full-review work. The [catalogue-first audit](catalogue-retrieval-scope.md)
separates required catalogue qualification/comparison from relevance-driven supporting
archive appraisal. Quiet criterion responses still need actual cited review; rendered
preparation alone receives no credit. No-header sources are unresolved, not excluded.
