For each native mutation retain a private receipt of account/client identity
(without tokens), target binding, allowed operation, preimage, result/readback,
as-of time and fallback if used. Keep operational IDs and real data out of Git.
Use existing authenticated routes; client installation or another client's login
is not permission evidence. Do not mutate shared authentication without coordination.
An access denial is a boundary, not a reason to request broader consent or try to
bypass it. Fallback delivery does not erase an unmet acceptance criterion: record
whether the user outcome is achieved with limitations or remains incomplete.
