# Readable historical comparison findings

The integration-owned SharePoint findings page presents the existing pack11
comparison evidence as readable paragraphs. It retains all76 provisional catalogue
comparison groups and24 source-only reviews:223 finding records and1118 citation
occurrences. It adds no appraisal, annotation, catalogue identity or human decision.

Each finding exposes its claim type, criterion, statement, proposed action, benefit,
effort, dependencies, uncertainty and recorded scope. Each evidence passage retains
its source ID/hash/locator and extra context. Comparator versions remain as recorded;
source-only catalogue identities remain unresolved. The complete985-row coverage,
original source files and original quotations stay in the linked versioned pack.

Passage whitespace is normalised for display before native serialization. The CLI
page parser removes literal CR/LF/TAB, which otherwise joins words across lines;
this was observed on the first draft and is covered by a regression. Original
verbatim quotations are preserved in the source pack. The first draft remains
unpublished. A separate corrected successor passed complete semantic HTML readback
before publication. The source pack's native identity/version/bytes were freshly
verified; raw file and canonical JSON hashes are explicitly distinguished.

Current-account browser readback contains all223 finding labels and1118 citation
occurrences. This does not establish ordinary-user access, current-policy authority,
clinical adequacy or accepted decisions. The page is a manual reading surface;
existing annotation and case records retain their writers. No operator CLI or
desktop Word step is required. New contributions do not edit this frozen snapshot.

## Recovery and ownership

recovery ZIP with exact pack JSON, expected HTML, bindings, source/page/preservation
receipts, renderer and three self-contained tests. Verify downloaded CRC/all hashes,
run `verify.py` and `python3 -m unittest tests.test_findings_web -q` in isolation.
Restore into a separate page; differing or human-edited content stops the writer.
Original comparator/source byte recovery remains in its existing archives.

Page publication uses the existing qualified CLI/SharePoint route, exact item ETag,
semantic readback and no-change replay. Earlier guides and maintained Word retain
their identities/versions/content. This is an evidence presentation, not a new
clinical workflow or Power Platform solution component; frozen workflow1.6 remains
unchanged. Current-source verification, clinical decisions, ordinary-user adoption,
measured benefits, full conversion fidelity and structured regeneration stay within
their separate recorded scopes.
