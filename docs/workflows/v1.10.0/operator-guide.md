# PPG workflow operator guide

Version 1.10.0 — baseline 2026-10-21.

Use the existing PPG workspace; no meeting or new channel is required. This guide describes available routes and their limits. It does not grant access, assign responsibility, issue policies or enable stopped pilots.

## Start with the completed fictional example

Open **PPG — Start Here → Completed fictional PPG walkthrough**. Inspect the closed review, its edited draft and case-filtered evidence, then the separate next review. Preserve these examples. Use fresh fictional references for another run and confirm current operation bindings with the lifecycle owner.

## Prepare an editable review package

**Route:** local-manual. **Maintainer:** Integration.

**Trigger:** Authorised package preparation. **Inputs:** Source snapshot and maintained template.

1. Select recorded metadata.
2. Populate draft template.
3. Retain source and output revision.
4. Open and edit draft.
5. Record missing review inputs.
6. For review intelligence verify source and template before substantive comparison.
7. Check title, printed identifier, original hash and latest source-association holds; do not substitute an unresolved conflicting source.
8. Account for every catalogue item and preserve unmapped content.
9. Carry unresolved annotations with full retained history and version reconciliation.
10. Store a new preparation revision with hash readback; hold missing evidence.
11. Inspect historical source content through source/reviewer-separated modules; preserve the original archive and unsupported elements.
12. Read provisional passage-backed findings and proposed next actions without promoting historical observations to the requested edition.
13. Use the versioned operator supplement to navigate qualified records and evidence.
14. Distinguish retained printed identifiers from catalogue assertions; explicit unverified variants never promote current-edition coverage.
15. Record document, template-candidate, criteria and draft-prompt versions plus available runtime and unresolved evidence.
16. Retain each annotation version state, document/section binding and native actor; never substitute current-row context for missing history.

**Output:** Editable unapproved draft package.

**Hold/recovery:** Stop only this operation; preserve inputs, prior output and operation identity. Reconcile actual effects before retry; never invent a decision or overwrite human edits.

**Evidence:** Historical171-element source capture and manual pack qualified within recorded limits. Consolidated pack10 accounts985 catalogue records,76 provisional source comparisons and908 metadata-only; later source-only and Word companions retain their own scope.
