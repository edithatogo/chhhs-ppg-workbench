## Find a file that search misses

Use the **download the full archive index (CSV)** link beneath the task links.
Open it in Excel and filter `originalFileName`, `hostedFileName` or `sourceUrl`;
follow `canonicalUrl` to the preserved copy. The index also retains capture date,
size, SHA-256 and the explicit captured-reference label. The verified download
accounts for all 533 archive documents and 317,586,380 original bytes.

Ordinary SharePoint search returned PDFs for a sampled policy term. An exact-path
query for one known `.captured` Office original returned no result despite its
presence in the archive. This is sampled discovery evidence, not an exhaustive
search-coverage audit or proof that a missing result means the file is absent.

Office originals keep the `.captured` suffix to preserve bytes. Download one and
remove only that suffix on the downloaded working copy to open it. Do not rename,
convert or overwrite the archived original to improve search. No OCR, AI agent or
derived searchable collection was introduced by this increment.
